# Galerie Maya public site snapshot

A static, page-by-page copy of the public site captured on 16 October 2026. It contains 191 fetched pages, including product, collection, and information pages, plus downloaded styles, scripts, fonts, and images where available.

## Preview

From this directory run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Before using as a replacement store

This is a visual and content starting point. Shopify checkout, cart, search, forms, account features, inventory updates, and other server-backed functions are not recreated. Some third-party or unavailable assets may still load remotely. Rebuild and test those features, review rights to use images and text, and confirm current product data before publishing.

The source site remains the authority for live commerce until a tested cutover.
